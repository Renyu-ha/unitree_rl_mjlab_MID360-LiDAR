# 轮足机器人感知运动控制：整套奖励对照

调研日期：2026-10-24。第1—5节比较基准为本仓库 `ac20bf95d7fed448cd047ed03c7406c24064a486` 的 Go2W 标准 V2 与 StepUp-Finetune，即本次奖励改动前的快照。第7节记录首批实现，第8—9节补充持续悬空调研；后续对称增强、力矩与观测实验见第10节。没有完成长时间训练或验证新增设计对策略表现的改善。

## 结论

本报告的主对照限定为**部署时地形感知参与低层运动控制**的轮足方法：S1 ETH/Swiss-Mile、S2 VIP-Loco、S3 SkateNav。S1的主动四轮足实机方案最接近我们；S2为主动双轮足仿真，S3为被动轮四足，作为补充机制参考。S4—S7只保留为背景资料，不作为感知方案差距的主要依据。

当前标准 Go2W V2 有 **15 个非零权重项**，StepUp-Finetune 有 **18 个**。感知对照中，S1有11个公开低层公式组，S2轮足列13个非零项，S3有11个命名组。分组口径不同，不能据此严格排名，但也没有证据认为我们在总数量上明显偏少。更明确的差距是：**缺少显式力矩代价、二阶动作平滑、选定非轮部位的环境接触惩罚。**机身相对地形高度是S1额外采用的目标；侧滑/滚动一致性是S3的专门设计。

没有固定步态或抬腿奖励不等于无法产生轮腿协同。ETH/Swiss-Mile 的感知轮足控制公开默认清单没有专门的固定相位/摆脚高度项，也实现了混合运动。[S1]

需要同时比较奖励函数、作用关节、触发条件、总奖励处理方式和训练任务；单独复制权重或增加条目不能保证改善。

### 1.2 感知训练链路的可比性

我们V2把带记忆的MID360兼容高度扫描直接给Actor，Actor输入保留3帧历史；扫描本身有0.8秒记忆及稀疏化、丢帧、延迟随机化。ETH采用教师训练加带噪高度扫描的GRU学生；VIP-Loco还引入深度内部模型及部署时规划；SkateNav把高程图编码、接触估计和相位控制接入策略。奖励差异只是这些系统差异的一部分，不能把表现差距全部归因于奖励。[S1][S2][S3]

本次主对照没有显示“带感知就必须有落脚地形奖励”。ETH主要奖励运动结果和正则性，让感知通过观测与地形训练支持动作选择；VIP轮足列的边缘项甚至为0。地形相关奖励可以作为实验选择，但不是这组证据支持的统一要求。

## 4. 扩展背景对照：不要全部归为感知方法的共同差距

本节包含S4—S7的背景信息。主要结论以1.1的纯感知矩阵为准；例如持续接触力、轮加速度、发热在下表的讨论不能理解为三种感知方案均采用。

| 类别 | 当前 Go2W | 与上述来源的差异 / 判断 |
| --- | --- | --- |
| 平面速度、偏航跟踪 | 已有 | 基础覆盖完整；形式和容差应比较，不需因别人拆x/y就增加条目 |
| 垂向速度 | **已包含在指数跟踪核内** | 不是完全没有；与独立`−vz²`的梯度和失配时约束强度不同 |
| 横滚/俯仰姿态与角速度 | 已有 | 角速度跟踪内部也含xy角速度；有重叠，增加前先检查贡献 |
| 机身相对地形高度 | 缺少显式项 | pose不能保证机身离地高度；可考虑高度容差带或地形相关目标 |
| 默认关节姿态、髋关节姿态 | 已有pose和停车姿态 | 我们按关节std给容差，包含hip；无需仅因名称不同重复加hip项 |
| 力矩/能耗/机械功率 | **缺少显式项** | 轮速小不等于电机用力小；执行器限幅不等于能耗目标 |
| 关节位置限制 | 已有，腿 | 覆盖软位置限制；轮无旋转位置目标合理 |
| 关节速度/力矩超限 | 无显式奖励 | 与物理限幅不同；是否增加取决于饱和占比 |
| 关节速度/加速度平滑 | 腿加速度+轮速 | 缺少独立轮加速度；轮速平方与轮加速度平方用途不同 |
| 动作平滑 | 一阶差分已有 | 缺少二阶差分/曲率项；可与一阶项做消融 |
| 自碰撞 | 已有 | 自碰撞不覆盖腹部/腿部与地形接触 |
| 非轮部位与环境接触 | **仅有诊断传感器** | 尚未变成对应奖励；可选择具体部位计罚 |
| 落地冲击 / 持续大接触力 | 仅首次落地力 | 缺少持续超阈值接触力项；两者不同 |
| 绊碰/撞台阶竖面 | 无独立项 | 部分来源按水平/垂向接触力关系检测 |
| 滚动空转 | 已有单向超速惩罚 | 不含独立侧滑与对称滚动速度误差 |
| 停车 | 腿姿态+轮速+速度跟踪 | 已有多项覆盖；是否漂移仍需评估实际机身速度 |
| 步态、腾空、跨步 | 当前无显式项 | 不必默认加固定步态；感知轮足已有无固定步态成功先例 |
| 进度、通过障碍、防卡住 | 标准V2无专用项；StepUp有前向速度下限 | 最低速度不等同目标进度；强制前进可能与必要减速竞争，需按任务设计 |
| 存活/失败 | 失败终止惩罚 | 与持续alive奖励是不同任务权衡，不宜只为补项数叠加 |
| 负载分配、发热 | 无显式项 | 同型号Go2-W研究提供了EMA力矩分布参考 |
| 奖励裁剪 / 尺度处理 | 需结合奖励管理器核对 | 例如DreamWaQ裁剪负总奖励；不同汇总方式下数字不能直接横比 |

## 5. 以感知主对照为依据的实验优先级

以下是根据S1—S3和本仓库静态覆盖作出的**实验建议**，不是已验证的改进。S1最接近我们的形态与任务，应给予更高参考权重。

1. **先评估用力、环境接触和平滑性。**记录逐关节力矩/饱和比例、`sum(tau²)`、指定非轮部位接触和动作二阶差分，以判断是否对应当前失败现象。
2. **第一批独立消融：力矩平方、选定非轮部位环境接触、二阶动作平滑。**三项都有最接近的ETH方案支持，力矩与碰撞也在其余两个感知方案中出现。分别加入并评估，不把三个变化混成一个结论。
3. **第二批按现象选择机身相对地形高度或滚动一致性。**高度容差带参考ETH，侧向/纵向滚动代价参考SkateNav的类别。机器人高度不能照抄0.55 m；转弯时应考虑逐轮运动学。
4. **再考虑任务进度、防卡住及步态。**VIP-Loco给出Stuck/Cheat项名称，但未核实其精确函数，不直接照搬。进度目标要容许必要减速；固定步态、抬脚或边缘奖励均不属于这组感知方案的统一要求。
5. **轮加速度、负载分配和发热另立扩展实验。**这些可由背景源码和长期实机需求推动，不作为本次纯感知对照的首要结论。机械功率也可记录，但不能声称这三篇都使用了功率奖励。

每次以当前奖励为对照，固定地形、感知课程、训练预算和评估指令；比较通过率、跌倒率、跟踪误差、触地、力矩/功率、动作平滑与停车漂移。不同随机种子用于判断变化是否稳定。不要仅凭总reward上升评价新增项。

补充注意：当前`pose`是有上界的正奖励，不能与其他项目无上界的L1/L2姿态惩罚直接按权重比较；`action_rate_l2`作用于不同scale的腿位置动作和轮速度动作，物理平滑强度也不同。已有`vz`和xy角速度约束时，新增同类项应视为改变强度/梯度，而不是从零补齐。

## 8. 平地直行/停车时单腿持续悬空

### 8.1 感知轮足的直接参考

**ETH/Swiss-Mile（S1）**：补充材料式(27)在“分层步态选择”对照实验中使用逐腿期望/实际接触匹配奖励 `0.1*sum_i 1(contact_i == target_i)`。最终方案移除了显式步态选择，不能说其默认奖励已用四轮接触约束。可借鉴的是接触状态目标；把平地停车的目标设为四轮接地，是本项目的候选设计，不是论文原有的恒定目标。[原文补充材料](https://arxiv.org/html/2405.01792v1)

**SkateNav（S3）**：滑行/推进/回收阶段定义轮接触、足接触和离地的目标，奖励随相位评估当前接触。它能约束“该接地时却悬空”的状态，但被动轮推进机构不同；策略还可把相位频率调到0，因此不能把相位配合等同于严格的最大离地时长约束。[§5.4、§5.6.1](https://arxiv.org/html/2610.25962v1)

**VIP-Loco（S2）**：公开表给出正的 Feet Air Time 权重，但没有核实到完整触发公式，不能据名称判断它会制止永久悬空，也不建议把鼓励抬脚的项直接用于当前问题。[Table I](https://arxiv.org/html/2603.14345v1)

上述资料没有提供专门针对“平地右前轮持续抬起”的消融结果。

### 8.2 支撑时间均衡：背景参考，不归为感知轮足证据

fuRo 的2025年 **Go2盲控四足**工作采用 `support_phase_ratio_std`：对四腿二值接触做EMA，再惩罚腿间标准差；附录给出 `p_t=0.1*c_t+0.9*p_(t-1)`、`cost=std(p_t)`。持续少支撑的腿会与其余腿产生差异。该工作另有鼓励低速抬腿的“接触过多”惩罚，后者不适合直接解决当前问题。[作者原稿，附录A](https://www.furo.org/irie/papers/ar_qrc2024.pdf)

2026年同团队 **Go2-W盲控**论文改用力矩均衡项，并明确区分其与接触时间比例均衡；停车还使用独立站姿策略。它不能算成低层带地形感知的方案。[§4.2、附录A](https://arxiv.org/html/2606.21387v1)

### 8.3 本项目建议，尚未加入配置

先核对四轮当前接触、世界Z向受力、当前离地时长和累计接触比例，顺序为 `FL, FR, RL, RR`。确认是无接触且无支撑力的真实悬空，而不是可视化或接触映射问题，再对照分项奖励；目前没有回放数据，不能断言根因。

当前 pose 只看12个腿关节相对默认姿态的平均误差，不要求轮子接地；soft_landing 仅落地瞬间计罚。它们都不直接约束单腿长期悬空。二阶动作和接触力平滑也不是持续接触目标：保持不动的悬空腿可以没有持续的动作/力变化。

建议优先独立比较以下候选，保持 slide 为相同背景条件：

1. **平地停车接触缺失代价**：在重置缓冲、接触去抖后，对当前缺失的轮接触逐轮计罚。需限制在可正常四轮支撑的地形，不能只凭零指令就在台阶/沟边强制四轮接地。
2. **连续超时离地代价**：`flat_gate*sum_i max(current_air_time_i-T_allow,0)^2`。每个控制步评估，不能只在落地时评估；阈值根据正常越障与换步时长统计选取，不照搬其他机器人的秒数。
3. **支撑比例不均衡代价**：参考EMA接触比例差异，允许短暂换步，抑制长时间只用三腿。相等比例不保证足够接触，所有腿都离地时差异也可为0，不能单独替代接触/姿态条件；EMA时间常数应按本项目控制周期重新选。

不要只惩罚右前腿，也不要在所有地形要求四轮同时接地。评估应包含平地前进/后退、停车、原地转向、上下台阶，比较逐腿最长连续离地时间、接触比例、受力、速度误差与通过率。目前仅完成调研，没有加入防悬空奖励，也没有声称新slide已解决这一现象。

## 9. 补充核对：已有工作怎样组织接触与避免偏腿

本节针对“平地直行或停车时右前腿持续悬空”。将带外部地形感知的工作作为主线；同形态盲控和通用对称性方法仅作补充。核对的是公开采用的机制，不把“演示里没有悬空”当成消融证明。上一节的连续离地超时项是本项目候选，**不是已核实的感知轮足领域通用配方**。

### 9.1 感知控制主线

| 工作 | 公开采用的机制 | 对当前问题的含义与边界 |
| --- | --- | --- |
| ETH/Swiss-Mile，Science Robotics 2024；主动四轮足 | 默认直接输出腿位置/轮速，移除CPG，使用跟踪、力矩、机身高度、碰撞等目标；另有式(27)接触目标跟踪对照 | 与我们最接近。默认清单没有单列最长离地时间/接触比例约束；不能说其成功来自防悬空奖励。对照方案提供接触目标参考，但不宜混称最终方案 |
| SkateNav，2026预印本；感知被动轮四足 | 滑行/推进/回收分别定义轮接触、足接触和离地目标，逐步按相位评分 | 应接地阶段悬空会少得接触奖励；频率可为0，不是严格的最大离地时间约束；不能直接移植被动轮推进周期 |
| Miki等，Science Robotics 2022；感知纯四足 | CPG生成周期足轨迹，IK后加策略残差；参考轨迹含抬升、下降、支撑段 | 带有持续回到支撑姿态的运动先验。与我们的直接关节输出不同；单独复制其平滑奖励并不能获得同样先验 |
| PGTT，2025预印本；感知纯四足 | 直接输出关节动作，用相位相关足高跟踪奖励覆盖支撑和摆动段，局部地形调节摆高；另罚摆动阶段触地 | 持续落脚引导来自支撑足高目标，不能把“摆动触地惩罚”本身说成防悬空；固定走路节奏需改成适合轮行的模式 |

来源：[ETH 2024正文与补充材料](https://arxiv.org/html/2405.01792v1)、[SkateNav §5.4与Table 2](https://arxiv.org/html/2610.25962v1)、[Miki 2022补充S5、S7](https://arxiv.org/html/2201.08117)、[PGTT §III-E](https://arxiv.org/html/2510.18348v1)。

PGTT的核心是 `sum_i exp(-(z_i-z_des_i(phase,terrain))²/sigma_f)`，其期望高度在支撑段回到名义高度；足高目标与真实接触仍非同一件事。Miki 2022的残差控制也没有给出“某腿绝不会长期悬空”的硬保证。

### 9.2 同形态盲控及偏腿研究补充

**Go1W，IROS 2025。**《Learning Robust and Flexible Locomotion of Wheel-Legged Quadruped Robots in Complex Terrains》采用随机化相位、占空比和频率的CPG接触模式，含trot、walk、drive；将模式用于轮高、轮速度和接触力三类奖励，Actor不显式输入/输出接触相位。它依赖IMU和关节传感器，是盲控。对我们有用的是包含连续轮行在内的接触模式训练，未见单独针对长期悬空的消融。[§II-B、II-D、Table I/II](https://rasevents.org/uploads/documents/pdfviewer/46/3c/200357-1697.pdf)

**fuRo 2025/2026。**前者接触时间比例均衡，后者Go2-W力矩均衡与独立站姿策略，具体见8.2。接触比例衡量是否长期少用一腿，力矩衡量用力分布，均非接触硬约束。2026工作的目标主要是减轻发热，不能将其效果改述为已验证消除单腿悬空。[2025作者原稿](https://www.furo.org/irie/papers/ar_qrc2024.pdf)、[2026 §4.2及附录A](https://arxiv.org/html/2606.21387v1)。

**Su等，Leveraging Symmetry in RL-based Legged Locomotion Control。**比较镜像数据增强和严格等变网络，针对常规RL产生的偏侧、不规则运动；有仿真与实机实验。它属于通用运动/操作控制参考，不能当成感知轮足防悬空实验。迁移到本项目时，镜像必须同时处理地形图、指令、历史状态与动作，且只使用机器人和任务真正成立的对称性；不是让左右关节每帧取同值。[正文§IV、§VI](https://arxiv.org/html/2403.17320)

另筛查CTBC的RA-L稿：其偏腿/偏向动作的对称性奖励在结论里属于未来工作，不计入已实现方案；且控制器为盲控双轮足。[结论](https://ctbc-for-wheeled-bipedal-robots.github.io/static/pdfs/RA_L_2026.pdf)

### 9.3 与我们比较后的判断

已有工作通过接触目标、分阶段落脚先验、支撑/用力均衡或对称性学习塑造腿的使用方式；没有证据支持只靠pose或动作平滑就能排除持续三轮支撑。调研时的Go2W虽保留phase观测，但没有对应接触或足高跟踪奖励，也没有CPG/IK参考动作；后续观测调整见第10节。

若保持当前直接关节控制结构，文献依据更明确的候选是：停车时的合适接触目标、低强度的接触时间比例均衡，以及针对固定偏侧的镜像训练。连续离地超时可以作为独立备选，与上述方案比较；全地形强制四轮接触、逐时刻四腿等力以及直接套固定trot都缺少与我们任务一致的支持。本轮只更新调研，不改训练代码或配置。

## 10. 后续实施：对称增强、力矩与无相位观测

按用户后续要求，所有Go2W任务启用左右镜像数据增强（RSL-RL原生增强，mirror loss关闭），新增腿/轮力矩平方惩罚，权重分别为 `-7.5e-6` / `-5.0e-6`。实现参考robot_lab思路，按mjlab自身配置、观测历史、执行器与RSL-RL接口接入。它们不等同于四腿力矩分配均衡，也不保证已经消除悬空。

同时注释Actor/Critic的phase和Critic的foot_air_time观测。接触传感器时间跟踪仍保留给落地检测，Critic接触力转到机身系后缩放，保证任意航向下的镜像含义正确。V2 Actor/Critic为720/263维，旧726/269维checkpoint不能直接加载。二阶action与GRF变化仍未配置。该阶段标准V2非零奖励18项，StepUp为21项。

49项CPU检查和2环境、4步采样的一轮实际PPO更新通过，覆盖几何镜像、历史、地形扫描、力坐标系、执行器选择及配置序列化。未完成长期训练效果评估。详细设置见 `doc/go2w_perceptive_zh.md` 第2.1节。

按后续要求补齐关节惩罚：保留上述两类力矩项、腿加速度 `joint_acc_l2=-2.5e-7` 和轮速 `wheel_speed=-1e-4`，新增腿速度 `joint_vel_l2=-5e-6`、轮加速度 `wheel_acc_l2=-2.5e-9`。轮加速度为本项目保守初值，未直接照搬robot_lab的数值；读取实际关节加速度，与仍未配置的二阶action不同。目前标准V2非零奖励20项，StepUp为23项。

补齐后50项相关CPU检查及同样规模的一轮实际PPO更新通过，包含全部Go2W训练/play配置的关节选择隔离与6项关节代价的原始数值有限性检查。尚未通过长期训练校准权重或评估悬空现象。

用户随后将轮加速度权重调整为 `-2.5e-8`，并将V2两类台阶的中央平台宽度改为2.0 m。各地形平台参数现集中在Go2W配置的 `TERRAIN_PLATFORM_WIDTHS`；以上历史初值和短PPO检查不代表调参后的长期效果。
